Proof: A Balanced 3-Phase System Produces a Rotating Magnetic Field

Consider a 3-phase stator having three identical windings (R, Y, B) displaced in space by 120°, fed by balanced 3-phase currents displaced in time by 120°.

Step 1: Instantaneous Alternating Fluxes

Each phase winding produces a pulsating sinusoidal flux along its own magnetic axis:

Φ_R = Φm · sin(ωt) ∠ 0°
Φ_Y = Φm · sin(ωt − 120°) ∠ −120°
Φ_B = Φm · sin(ωt − 240°) ∠ −240°
Step 2: Resultant Flux (Φ_net) at Key Instants

Case I: When ωt = 0° Inspect ↗
• Φ_R = Φm · sin(0°) = 0
• Φ_Y = Φm · sin(−120°) = −(√3/2) Φm
• Φ_B = Φm · sin(−240°) = +(√3/2) Φm
Resultant: Φ_net = 2 · (√3/2 Φm) · cos(30°) = 1.5 Φm (at 90° / Vertical)
Case II: When ωt = 60° Inspect ↗
• Φ_R = Φm · sin(60°) = +(√3/2) Φm
• Φ_Y = Φm · sin(−60°) = −(√3/2) Φm
• Φ_B = Φm · sin(−180°) = 0
Resultant: Φ_net = 1.5 Φm (Rotated by 60° clockwise!)
Case III: When ωt = 120° Inspect ↗
• Φ_R = Φm · sin(120°) = +(√3/2) Φm
• Φ_Y = Φm · sin(0°) = 0
• Φ_B = Φm · sin(−120°) = −(√3/2) Φm
Resultant: Φ_net = 1.5 Φm (Rotated by 120°!)
Step 3: General Analytical Vector Proof (For Any Angle ωt)

Resolving all three space phasors into horizontal (x) and vertical (y) components:

Φ_x = Φ_R·cos(0°) + Φ_Y·cos(120°) + Φ_B·cos(240°)
Φ_x = Φm[sin(ωt) − ½sin(ωt−120°) − ½sin(ωt−240°)] = 1.5 Φm · sin(ωt)
Φ_y = Φ_R·sin(0°) + Φ_Y·sin(120°) + Φ_B·sin(240°)
Φ_y = Φm[0 + (√3/2)sin(ωt−120°) − (√3/2)sin(ωt−240°)] = −1.5 Φm · cos(ωt)
Magnitude: |Φ_net| = √(Φ_x² + Φ_y²) = 1.5 Φm (Constant!)
Angle: θ = tan⁻¹(Φ_y / Φ_x) = ωt − 90° (Rotates at synchronous speed Ns = 120f/P!)

Key Exam Takeaways

  • Constant Magnitude: The resultant flux always has a constant peak value of 1.5 Φm.
  • Synchronous Speed: It rotates smoothly at Ns = 120f / P rpm.
  • Direction Reversal: Swapping any two supply phases (e.g., Y and B) reverses the direction of rotation.
